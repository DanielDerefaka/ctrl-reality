## Included and validated

- Complete game design and judging strategy.
- Official-rule constraints captured as of September 22, 2026.
- Art/style lock and 12 detailed 404 object briefs.
- Codex master prompt plus eight sequential build sessions.

- Five architecture/gameplay diagrams.

## What this pack is not

This ZIP is not a finished competition entry. It has not:

- connected to the organizer’s private/actual 404 MCP,
- generated and visually selected final 404 3D assets,
- been played on the user’s physical phone,
- been deployed to the final public host,
- passed the organizer’s current official live gate,
- received a real final commit SHA, wallet, team handle, or contact,
- guaranteed any prize result.

Those claims would require work and evidence from the actual project environment.

## Prototype warning

The starter’s `game/assets/prototype-assets.js` uses ordinary Three.js primitives solely to prove mechanics. It is prominently labelled `PROTOTYPE_ONLY`. Codex must replace those visible objects through the current 404 recipe before submission.

## Test result in this pack environment

The included pure-logic test suite was run while assembling the pack and passed 11 tests. Rerun it after extracting and after every relevant change. The browser build still requires installing its pinned development dependencies and copying local Three.js.
