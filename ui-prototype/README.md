# Production UI Prototype

This prototype is a visual and interaction reference for Codex. It is deliberately independent of Three.js so the interface can be reviewed before the game renderer is ready.

Open `index.html` through a local server. Use:

- `?screen=title`
- `?screen=hud`
- `?screen=result`

Keyboard shortcuts: `1`, `2`, `3`. The bottom desktop toolbar is outside the phone frame and is not part of the game.

## What should carry into the game

- information hierarchy,
- safe-area spacing,
- size and position of the three controls,
- clock ring and Second Hand slots,
- restrained materials and typography,
- clear press/active/disabled states,
- result-panel density,
- no full-screen tutorial wall.

The SVG vault scene is a composition mockup, not a permitted final 3D asset. All final 3D objects still require the 404 recipe.
