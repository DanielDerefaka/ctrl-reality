## Commit rules

- One purpose per commit.
- Tests included with the behavior they protect when practical.
- Asset source and receipt travel in the same commit.
- Do not commit tokens, secrets, local browser profiles, `node_modules`, or large unused candidate outputs to the final game folder.
- Candidate evidence may live in production documentation or release assets, but only selected assets belong in the active runtime manifest.
- Never rewrite public history merely to appear more active.
