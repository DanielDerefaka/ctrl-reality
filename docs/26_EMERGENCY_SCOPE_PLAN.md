# Emergency Scope Plan

Use this only when schedule evidence says the full plan is at risk. Cutting early protects finish quality.

## Trigger A — Core loop does not pass by midday September 23 WAT

Cut immediately to:

- one chamber,
- one echo,
- one plate,
- one gate,
- one jewel,
- one signature rewind.

Do not generate production assets until that path passes a custom gate.

## Trigger B — Core passes, but P0 assets are under 50% selected by midday September 24

Ship one room with three configurations rather than three visibly distinct environments. Generate only:

- thief,
- floor,
- plate,
- gate,
- crank,
- second hand,
- pedestal,
- modular wall/arch.

Build latch and exit from parameterized variants only when current organizer rules allow that reuse and each visible object remains documented.

## Trigger C — Performance exceeds internal budget after art integration

Cut in this order:

1. decorative gear clusters,
2. dynamic shadows on secondary objects,
3. transparent trails density,
4. pendulum geometry complexity,
5. wall-bay count,
6. separate material variants,
7. device pixel ratio.

Do not first damage the thief, gate, plate, or jewel silhouette.

## Trigger D — Chamber 2 or 3 is confusing in fresh playtest

Do not add tutorial paragraphs. Instead:

- remove one mechanism,
- shorten routes,
- make the physical link visible,
- freeze the hazard during the first demonstration,
- move the mechanism into the same camera composition.

A clear two-stage game is stronger than an opaque three-stage game.

## Trigger E — Final live gate fails inside deadline buffer

Only make hosting/build corrections and the smallest verified blocker fix permitted by current rules. Do not add polish. Restore the last known passing release if the new fix cannot be fully rerun.

## Minimum viable memorable submission

The irreducible game is:

> A beautifully generated clockwork room where the player demonstrates a route, rewinds, watches a porcelain past self repeat it and hold a plate, then walks through the gate that their own previous performance opened.

Everything else is optional compared with making that moment reliable and beautiful.
