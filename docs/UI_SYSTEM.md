# Typography and interface

Display: locally bundled Cormorant Garamond. Interface: locally bundled Manrope. Both are SIL Open Font License; license files ship beside fonts. Title uses deliberately spaced capitals, a cyan double slash, ivory lettering and substantial empty space. Do not rasterize text into media.

Desktop: title copy begins at 7.3% width, menu is a quiet 300px column; wide scene remains visible at right. One cyan leading edge indicates the primary action. Avoid excessive glowing boxes and icon clutter. Footer and edition metadata are subordinate.

Phone 390×844: title moves to the lower half with a darker readability gradient; character is framed above and behind it. Main actions are at least 58px tall. Gameplay uses 64px pause, 72px ACT and a 98px joystick; control cards are 108px. Settings have labels and values, visible keyboard focus, native range semantics and switch labels. Pause/how/settings/results keep their action inside the viewport.

HUD: sector/objective upper left, responsive sector route top, counters lower left, three control cards bottom center. Only BRIGHTNESS is available. Socket feedback is physical inset glass, latches, local light and a held 3D card; the greybox projected marker is removed. Real keyboard alternative avoids requiring dragging for access.

Focus is constrained to open menus and restored on closing a panel. Escape pauses/resumes or returns. Reduced motion removes video and camera interpolation. Mute and bus levels persist. No runtime implementation or debugging terminology is shown in the gameplay flow; the creation log is the explicit provenance exception.

Visual-lock type scale: desktop sector 12px, title 34px, objective 16px, card labels 14px and status numbers 28px; portrait 12/30/14/13/26px. Safe margins are 36px desktop and 18px portrait. Input guidance is in How it works and contextual prompts; no persistent developer key legend.
