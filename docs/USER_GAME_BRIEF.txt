==================================================

Build a highly polished, cinematic, third-person puzzle-adventure vertical
slice for the 404 Game Jam.

The game must:
- look premium
- play smoothly
- have a real main menu
- have a real HUD
- have sound effects
- have music
- have a clean pause screen

3. WORLD, STORY, AND PLAYER FANTASY
==================================================

The game takes place inside a broken reality archive: a monumental impossible
space made from obsidian glass, ivory ceramic, liquid bronze, luminous cyan
interface glass, and violet corruption.

The player character is:

MARA
A masked interface conservator who restores a collapsed system by taking user
interface controls out of the HUD and attaching them to physical sockets in
the world.

The player fantasy is:
“I am restoring a broken world using the interface itself as my tool.”

There is no shooting.
There are no generic drones.
There is no wave combat.
There is no inventory system.
There is no open world.
There is no giant content-heavy campaign.
This is a focused premium 6 to 10 minute vertical slice.

==================================================

- broken gap

- bridge reveal

- BRIGHTNESS

SECTION 2: CLOCK GALLERY
Theme:
- moving architecture
- pendulum
- rotating structures

Mechanic:
- PAUSE

Theme:

Mechanic:
- UNDO plus previous controls
