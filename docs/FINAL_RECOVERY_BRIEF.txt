7. DEEPEN BRIGHTNESS INTO THE COMPLETE GAME
==================================================

BRIGHTNESS must become a real gameplay system, not a single unlock button.

The deployed BRIGHTNESS control has three usable values:

DIM
- hidden symbols and shadow paths become visible
- radiant structures disappear
- corruption becomes less active

BALANCED
- sockets, engravings, and interactive markings become readable
- ordinary architectural routes remain stable

RADIANT
- bridge segments and light architecture materialize
- bronze channels energize
- some unstable surfaces become dangerous

Implement three short connected challenges:

CHALLENGE 1: REVEAL

- Pull BRIGHTNESS from the HUD.
- Install it into the first socket.
- Raise it to RADIANT.
- Build the first bridge.
- Cross to the next platform.

CHALLENGE 2: READ

- Retrieve BRIGHTNESS.
- Install it in a gallery mechanism.
- DIM reveals a sequence of archive glyphs.
- BALANCED reveals the socket order.
- RADIANT hides the glyph solution.
- Player must inspect and remember the sequence.
- Correct activation opens the next route.

CHALLENGE 3: STABILIZE

- Install BRIGHTNESS into the Reality Kernel.
- DIM reveals corruption nodes.
- BALANCED allows interaction with those nodes.
- RADIANT rebuilds the Kernel after the nodes are cleared.
- Complete the restoration sequence.

This creates a complete beginning, middle, and ending using one mechanic.

Do not add complicated combat or enemy AI.
