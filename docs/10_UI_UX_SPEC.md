# Zero Hour interface

Functional screens: Boot, Main Menu, Operations, Briefing, Gameplay, Pause, Results. Menu controls: Operations, How to Play, Settings, Credits. One real mission card: Operation Dead Clock, Nexus-9, steal the core, critical threat, target eight-minute full mission. Normal/Hard select real target durability. Briefing is skippable. Results never fabricate core completion or a rank.

HUD: upper-left mission/objective with change animation; top compass and objective bearing/distance; upper-right recording/readiness/cooldown and active echo count; lower-left segmented health/armor; lower-right carbine ammo/reserve/reload; center reticle, hit/critical marker, interaction and targeted enemy health. Recording and deployment effects are real. Damage feedback remains a dormant shell until enemies deal damage.

Black translucent panels, fine cyan borders, white main text, amber objectives, red alerts, violet echoes. Essential text >=12px, targets >=64px; no fake controls or debug labels. The Credits screen honestly identifies prototype content. Test 390×844 and desktop, and inspect rather than trusting element rectangles alone.

Mobile: left joystick/right drag; Fire, Echo, Dodge, Aim, contextual Use, ammo reload and Pause. Separate pointer ownership and cancellation. Do not cover the operative with meters or notifications. Sensitivity/invert/sound/haptics are functional settings. Real phones still require manual validation; emulation is not device evidence.
