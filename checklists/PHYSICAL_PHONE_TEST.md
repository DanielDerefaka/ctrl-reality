## Launch

- [ ] HTTPS/local network URL opens without warning.
- [ ] First meaningful screen appears promptly.
- [ ] Start requires one clear tap.
- [ ] Audio unlocks only after tap; no autoplay error.
- [ ] Page does not scroll, bounce, select text, or zoom during play.
- [ ] Safe areas avoid camera cutout/home indicator.

## Controls

- [ ] Joystick begins wherever intended and does not jump the player.
- [ ] Movement direction matches thumb direction.
- [ ] Releasing/canceling touch returns movement to zero.
- [ ] ACT works while another finger holds joystick.
- [ ] REWIND works while another finger holds joystick.
- [ ] Buttons show immediate press state.
- [ ] No stuck input after notification, tab switch, or orientation change.

## Readability

- [ ] Player remains easy to identify.
- [ ] Echo colors/shapes are distinguishable.
- [ ] Timer is readable at a glance.
- [ ] Objective and interaction prompt do not cover play.
- [ ] Plate, gate, crank, hazard, jewel, and exit states are obvious.
- [ ] Dark floor retains route contrast.

## Complete route

- [ ] Complete Chamber 1 using touch only.
- [ ] Complete Chamber 2 using touch only.
- [ ] Complete Chamber 3 using touch only.
- [ ] Restart one chamber.
- [ ] Clear echoes and recover from a bad recording.
- [ ] Finish a run after backgrounding/foregrounding the browser.
- [ ] Result screen and replay work without reload.

## Performance and stability

- [ ] No obvious sustained stutter.
- [ ] Rewind stays smooth/readable.
- [ ] Device does not become severely hot during a 20-minute run.
- [ ] No crash, black canvas, context loss, missing audio, or missing asset.
- [ ] No browser console/network issue when inspected remotely, if available.
