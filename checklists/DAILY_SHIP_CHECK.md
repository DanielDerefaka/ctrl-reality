# Daily Ship Check

Run once at the end of each working day so deployment is never a final-hour surprise.

- [ ] Clean checkout/setup still works.
- [ ] Local static server works.
- [ ] Unit tests pass.
- [ ] Custom Chamber 1 gate passes.
- [ ] Current build deploys to the intended host.
- [ ] Live URL opens on phone.
- [ ] No missing files or stale cache mixture.
- [ ] Current ready/transfer/draw/triangle metrics logged.
- [ ] Decision, discard, playtest, tooling, and gate logs updated.
- [ ] Public commits pushed.
- [ ] Next day begins from a passing build.
