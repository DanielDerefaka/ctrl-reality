# First 60 Minutes Checklist

The goal is momentum and evidence, not visual polish.

## Minute 0–10

- [ ] Create/open the public repository.
- [ ] Copy this production pack into it.
- [ ] Add `.gitignore` for `node_modules`, logs, browser profiles, local secrets, and temporary captures.
- [ ] Commit: `docs: commit second hands design baseline`.
- [ ] Clone official `404-game-recipe` next to the repository.

## Minute 10–25

- [ ] Read current organizer setup and run self-test.
- [ ] Record organizer commit and real result in `production/TOOLING_LOG.md`.
- [ ] Inspect actual MCP tools; record 404 connection truthfully.
- [ ] Read `AGENTS.md` and paste the master prompt into Codex.

## Minute 25–45

- [ ] Install pinned dependencies.
- [ ] Copy local Three.js into `game/vendor/`.
- [ ] Start local server.
- [ ] Open the starter scene at 390 × 844.
- [ ] Verify Start, joystick, ACT, REWIND press states.

## Minute 45–60

- [ ] Fix the first blocking error only.
- [ ] Run unit tests.
- [ ] Save one floor screenshot.
- [ ] Commit the environment/floor when acceptance checks pass.
- [ ] Begin Session 02; do not begin asset generation.
